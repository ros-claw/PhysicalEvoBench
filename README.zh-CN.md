## 三种子、三轮正式确认（2026-10-24 登记）

**本次未证明稳定自进化，五项预注册科学判据全部未通过。** 已完成 **18 个 PPO 训练任务、11,059,200 个真实 PhysX 训练转移、4,610 个评测回合**；全部模型与优化器完整性审计通过，但参数更新不等于能力稳定提高。九个持续学习候选均被拒绝，每个都未通过手指最大越限深度门槛，三条轨迹最终都保留原模型。

持续学习最终为 **93/384**，原模型 **87/384**，同模型重放 **93/384**；持续学习三条轨迹的保留权重与原模型相同，这些差异属于执行波动。同模型安全重放有 **3/3** 组未通过相同门槛，说明本轮安全检查受重放波动影响；没有因此追认任何被拒候选。

另行预注册的 **576 回合、192 个全新配对条件**诊断，不追加训练，不挑最佳快照，评测全部轨迹的最后一轮原始候选：原模型 **46/192**、原始持续学习 **68/192**、最后一次原始重训 **68/192**。原始持续学习相对原模型为 **+11.46 个百分点**，多重比较调整后的条件区间 **[+0.52, +22.40]**。三条轨迹分别为 **16→32、11→28、19→8**（每组 64 条件），第三条下降；与同预算最后一次重训的合计差为 0，调整后条件区间为 [-10.94, +10.94] 个百分点。这项诊断不能替代接纳、安全和多轮稳定性检验。

全部组共享 ±1000 原始动作单位的数值包络，沿用上游官方抬升成功定义；提前终止的正式回合不测量持续持稳。此前完整时域持稳校准仍为失败（原模型 0/12 次低速持稳），数值溢出失败也完整保留。本次调查合计 **14,745,600 个训练转移、5,238 个评测或诊断回合**，各研究分别推断，不混成一次成功证明。区间只对三条固定学习轨迹的条件重采样有效。

## 2026-10-23：真实权重学习已跑通，稳定收益未确认

PPO 完成 614,400 个真实物理转移、200 次 PPO 迭代。验证集 6/24→8/24 后冻结模型；首轮全新测试 **4/32→10/32**（+18.75 pp，条件区间 +3.125～+34.375 pp，p=0.0352）。发现顺序分层后，在 **48 个新条件、96 回合**中使用各策略独立环境进程并交叉分配 GPU，结果 **12/48→15/48**（+6.25 pp，区间 **−12.5～+25 pp**，p=0.3318）。**更严格确认未证实稳定提升，不能只引用首轮正结果。**

测量退化正对照通过，手工几何专家未跑通；固定源码的新进程重放仍有 2/12 个成功标记分歧。关节越界总计下降，但一根手指最坏深度增加，不能声称全面更安全。全部 **422** 个完成评测/诊断/演示回合、2,467 个完成训练回合及失败记录均保留；未完成训练 rollout 单列。详见[完整结果](docs/experiments/CALIBRATION_LEARNING_RESULTS_20261023.md)、[预注册及修订](docs/experiments/CALIBRATION_LEARNING_PROTOCOL_20261023.md)和[证据包](docs/evidence/calibration-learning-20261023-001)。
