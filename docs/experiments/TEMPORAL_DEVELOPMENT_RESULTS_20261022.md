# 时序技能开发：训练探索与独立验证

**本阶段共完成 128 个真实物理 episode：96 个训练探索、32 个独立验证；留出测试为 0。**

新增可学习参数是夹爪闭合保持步数和机械臂动作指数平滑系数。默认值严格复现原策略。闭爪保持只依据公开动作指令及步数触发，不读取质量、种子或测试结果。机器人驱动力限、质量分布、任务成功条件、控制频率和 5 秒时限均未修改。

**预先固定的 gate：rollback。** 晋级条件是候选成功次数严格增加，且越限采样总数不增加。16 对条件使用全新种子、相同配对初始状态、随机平衡执行顺序。候选依据训练结果选定，验证数据未进入更新器。

候选未能通过预先固定的独立验证，已回滚；按计划不进入正式留出测试。本阶段没有支持该更新可泛化。

## 验证与证据

两个阶段均独立重建每一步动作，核对 float32 平滑状态、闭爪保持时长、技能哈希、官方分数、物理质量读回、关节计数、配对初始状态、预算和 train/validation 隔离，审计 PASS。

关节越限采样不等于事故次数；碰撞仍未测量。不得据此建立完整安全结论。全部失败候选与负结果保留，不将最优训练成绩冒充测试成绩。
