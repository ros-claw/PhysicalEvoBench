# 基于状态的参考控制器：开发与独立复测

本阶段接续PR #7的W3失败，不追加PPO或实际Agent比较。旧153回合和门控结果不变。新分支experiment/state-based-reference，GPU2单worker顺序运行，A6000共享资源、逐worker记录负载，不停止其他任务。

## 控制器与不变项

旧教师按第100/130步闭合/提升，新教师按实际状态切换approach→descend→close→probe→lift→hold。位置和姿态需到位；闭合需双指cube接触和非空夹爪开度；接触后先小幅试提，实际物体提升且相对末端位置保持，才允许朝任务目标提升。未抓到或丢失物体时先张爪退回，最多一次恢复。所有输入是公开几何、速度、接触与命令，不含质量、seed和评分结果。任务成功仍由独立post-physics持稳评分器计算，教师阶段名不算成功。

物理硬件、碰撞、重力、惯量规则、驱动与执行层保持原版本。共同执行层arm1rad/s、finger0.04m/s与live限位，严重边界不变。目标episode内固定；默认仍5秒、50Hz、0.05m/0.2m/s/0.30秒持稳。状态配置、推理YAML与不可变源码在每批物理启动前绑定哈希。旧GeometryExpert代码保留。

## 固定开发上限与条件调整规则

开发最多3批，每批4个全新0.1kg条件，最多12个实际回合；不是12个独立确认样本。首批固定默认状态机和5秒规则。每批先提交代码/配置、再登记独立随机条件与完整预算、再运行并读取结果。后批允许依据阶段误差/接触证据修改教师控制参数，不能修改物理硬件或评分阈值；完整保留所有批次。

只有前批证据表明仍在合法接近、下降或抓取阶段就耗尽5秒，才允许在后续批次测试明确命名的10秒诊断版本state-reference-h10-v1。该版本改变时限，必须新注册；不得把结果补记进旧5秒任务、不得宣布旧W3被挽救。原5秒新教师版本为state-reference-h5-v1。不得为本次结果临时修改成功标准。最多12次开发后仍不满足候选冻结条件，停止扩大开发，报告明确失败位置及下一步可验证假设。

开发冻结资格：某一批4回合至少3次有效持稳，且该批无>1mm关节越界或严重事件。仅是进入独立复测的资格，不是方法有效性证明。若最早一批满足，则不消耗剩余开发预算；冻结其源码和控制器配置，后续不修改后再确认。

## 独立复测

仅有上述资格时启动。新条件0.1/0.4kg各6个seed，共12个reference回合，加同条件12个StateBasedReferenceOpen负对照，共24。新进程分别运行两控制器，组内reset。版本/时限、硬件、执行层和评分完全相同；独立种子在注册前排除已有公开及本地开发注册。参考通过条件为每个质量档至少5/6有效持稳、全部12回合无>1mm关节越界或严重事件；张爪负对照有效持稳0/12。公开逐条件数据和样本规模限制，不以这些数值保证未来绝对安全。复测失败即保留失败，不能换一批seed重试宣布通过。

所有回合先预留、失败照计成本；终态在reset前记录，逐物理子步审计。正对照未通过前，实际W4/W5仍不运行。通过新版本也不等于稳定自进化；下一阶段才做参数作用与Agent接入。
