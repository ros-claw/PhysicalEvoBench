# 参考控制器v2：有界载荷误差补偿

在v1独立复测参考组完成、负对照仍在运行时提交，不读取任何v2新条件结果。v1参考组0.1kg为6/6有效持稳，0.4kg为2/6，参考门槛已失败；仍须跑完全部负对照并保留原失败。不得用下一组seed把不变的v1重新宣布通过。

## 新控制器与依据

v1失败回合已验证抓取、无>1mm越界，但升向目标后长期保留约0.09m或其他厘米级偏差。原机器人关节PD stiffness=80，原教师对机器人自身重力做前馈；每步从实际关节位置起算短步DLS目标，没有积累持续负载误差的机制。这是控制器反馈不足的可检验假设，不是已经证明唯一根因，也不使用真实质量做补偿。

v2只在已确认物体随动后的lift/hold阶段，对有界DLS关节反馈增量积分：gain=1.0/s、每关节积分位置偏置限制±0.12rad；其他阶段和episode reset清零。仍使用原position/rate执行层、原驱动/effort/速度/接触配置，物理参数不变。积分量和输入增量逐步记录并独立重算。任务仍为独立的十秒版本，不改变旧五秒结果。

## 剩余开发与唯一复测

原开发上限12回合已用8，batch3使用剩余4个全新0.4kg条件，配置在运行前固定，只测试上述一个v2。原参数作用协议因v1未通过，实际0回合、不启动；此批不把参数作用测试伪装成同一件事。若v2本批≥3/4有效持稳、全批无>1mm越界/严重事件，则冻结新源码及配置。

只有这个新的、实质改变过的控制器取得资格，才另注册**一次**24回合独立复测：0.1/0.4kg各6个新条件，v2参考12回合、同源强制张爪12回合。完全保留v1的24回合失败，不挑掉、合并或替换。v2参考每档至少5/6有效持稳、参考12回合无>1mm越界或严重事件、张爪0/12持稳才通过。若v2也失败，本阶段停止，不启动更多开发或复测，不运行实际Agent/PPO研究。

因此本阶段最大物理预算为12开发+24 v1确认+24 v2确认=60，分段资格不满足则实际少于上限。所有试验先提交/注册后运行，记录全部成本。改变了控制程序，因此v2确认是新研究，不能描述为同一个冻结控制器重试过关。独立验证集不反馈给未来Agent。
