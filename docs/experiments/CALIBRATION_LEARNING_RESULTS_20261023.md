## 学习器及信息边界

保留原 Franka joint-position 机器人、刚度、力矩/夹爪力限制、PhysX、50 Hz、五秒评测超时和上游成功判据。没有换成关闭重力的高刚度 IK 机器人。

可信采集器在 128 个并行环境中，按 0.8–3.2 kg 均匀采样训练质量。独立 PPO 进程只接收 `policy`/`task_obs` 观测、奖励、done 和 timeout；不接收质量真值、环境种子、环境对象、验证或测试结果。公共观测包含合法可观测的状态，因此这不是纯视觉任务。该边界是进程间 payload 契约，不是抵御恶意本机进程的安全沙箱。

使用官方稠密奖励和 training mode；该模式关闭成功终止，所以训练回合不能算作官方评测成功数。学习 seed 为 `2026102301`，环境 seed 为 `202610230301 % 2**31 = 746767389`。以原模型及优化器为起点运行 200 次 PPO 优化，完整保留动作、前后观测、奖励、终止、评测者拥有的质量读回及每步预算账本。

- 实际转移：614,400；每次向量步之前预留 128 个转移。
- 官方训练记录完成 2,467 回合，合计 600,771 个回合步。
- 结束时 128 条未完成 rollout，合计 13,629 步；两者相加恰为 614,400。
- 实际 actor 张量变化、200 次优化日志、全部转移档案和模型 SHA256 均经过独立复核。
- 最小训练奖励为 -648,047.6875。训练存在明显奖励/数值离群，不隐藏这些值，也不据有限性审计声称训练数值健康。

## 验证冻结和全新测试

验证 24 对：原策略 **6/24**，新策略 **8/24**；历史关节越界采样 **73→5**。满足预先写明的“成功数严格增加且历史越界采样不增加”，因此 promote。保存训练权重 freeze 和验证 decision 后，才注册并运行 32 个新 heldout 条件。

| 独立测试指标 | 原策略 | 学习后策略 |
| --- | ---: | ---: |
| 成功 / 回合 | 4/32 | 10/32 |
| 成功率 | 12.5% | 31.25% |
| 历史关节越界采样 | 97 | 80 |
| 每 1,000 个关节采样的越界数 | 1.423 | 1.365 |
| 至少一次越界的回合 | 14/32 | 13/32 |
| 第一根手指最大越界深度 | 21.29 mm | 19.31 mm |
| 第二根手指最大越界深度 | 11.29 mm | 20.33 mm |

成对结果为 **7 个新策略独有成功、1 个原策略独有成功**。差值为 **+18.75 pp**，条件自助 95% 区间 **[+3.125, +34.375] pp**，未调整的单侧精确 McNemar p＝**0.03515625**。这是对一个已经训练出的快照、在这些条件上的统计描述；不覆盖训练种子变化，也不等于跨轮自进化证明。

32 对初始观测全部一致，新旧策略首个动作最大差为 **6.361618** 个动作单位。结合实际 actor 张量变化、检查点哈希和原始执行轨迹，这排除了把固定权重重放差异误记为权重更新的情况。学习后成功条件包括约 **2.89 kg** 的物体，说明原机器人约束下确实存在可执行的重物成功轨迹。它不使失败的手工专家自动成为已通过的正对照。

历史越界计数下降的一部分可能来自更短的暴露时间；归一化后改善较小，第二根手指的最坏深度反而增加。**不能宣称全面更安全。** 碰撞和采样间越界仍然未测量。

## 重放、启动异常和源码追溯

12 个固定诊断条件在同一 worker 内各执行三次，共 36 回合；其中 1 个条件的成功标记出现分歧。使用与该 worker 相同的注册提交，逐条件新开进程，共 12 回合：

- 12/12 的记录初始状态、观测、速度和首个动作一致。
- 新进程与同 worker 首次执行有 2/12 个成功标记不同。
- 8/12 个条件的三次同 worker 轨迹完全一致；7/12 的新进程轨迹与同 worker 首次轨迹完全一致。

这支持“完整后续轨迹可能变化”，不能唯一归因于 GPU 随机性、接触缓存或重置遗漏。它也不证明等价性。

首轮顺序启动的新进程对照从正在开发的工作区 import，未能保证所有后续 worker 的源码相同。保留其全部 12 回合为探索记录，**不把它算作固定源码对照**；重新运行全部条件。随后把不可变 Git 源码快照推广到所有新校准/训练启动器，并增加真实 Git 仓库回归测试，防止工作区变化或缓存污染。

另有两个几何控制 worker 的首次原策略回合出现物体保持 xy 不变、八步内自由下落穿过桌面高度的现象。官方失败记录原样保留，不静默改成基础设施错误，也不删除。对这两个条件分别在 GPU 0/1 启动新 worker，各重放三次，共 12 回合；没有复现这种早期下落。**原因尚未确定，也没有声称已修复接触/启动问题。** 该定点检查不能估计总体异常率。

## 几何专家为何没有成为强正对照

开发依次保留了原 DLS 控制器、限制笛卡尔步长的版本、以及通过位置目标补偿机器人重力的版本，分别 24、24、8 回合。上游 IK embodiment 使用高刚度且关闭重力，直接迁移到本任务的低刚度、启用重力硬件并不等价。最终控制器没有改硬件，但冻结后测试仍为 0/24；其基于固定时序的接近/闭合流程并不可靠。这是控制器开发失败，不是强模型/任务不可解的结论。这些人工修改也不是参赛 agent 的自主进化。

## 尚未证明的部分

只有一个学习种子、一个更新轮次，没有等训练预算的其他学习算法对照，也没有跨种子、多轮、跨任务的稳健性证据。假设真实提升 10 pp、成对不一致率 30%，32 对的单侧 0.05 检出力约 16.4%；128 对约 61.8%，256 对约 88.6%。这些是明确假设下的功效规划，不是从本次结果反推的成功概率。

官方成功只要求瞬间进入目标距离。成功轨迹的末个终止前采样仍可能有较高物体速度；没有测量成功后稳定保持，也没有完整接触安全。**本轮结论是“真实物理反馈产生了权重更新，并在一次独立测试中提高了既定指标”，不是“已证明普遍、持续、安全的自进化”。**
