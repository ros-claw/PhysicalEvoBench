# 已校准参考控制器的参数作用诊断

仅当新十秒任务的独立参考/张爪校准通过才启动；尚未读取本阶段新条件结果。本阶段是参数作用开发诊断，不是Agent学习比较。

共4个实际回合，计入原12回合总开发上限：之前两批8个，加本阶段4个，合计12。独立参考确认的24回合另列。使用一个全新0.1kg条件，固定GPU2、冻结的同源十秒参考代码、原执行层和评分器。四个worker依次为：baseline、相同artifact的identity重放、approach_clearance_m改为0.12、minimum_close_s改为0.70；其余配置保持一致。每个worker单独新进程，初始状态读回必须匹配。相同内容不创造新候选，identity仍计实际物理成本。

检查raw→processed→实际下发target是否改变，以及第一次实际差异与阶段切换。clearance在第一步、任何新物理差异发生之前就应改变笛卡尔目标；close等待应在相同公开观测重算中改变阶段切换时机。不能只凭修改配置或raw输出就认定执行层已响应；至少一个实际applied_target差异必须超过1e-5。若参数被执行层完全吞掉，标记未验证，不把它暴露为已有效的Agent变量。

每个变体均公开有效完成、风险、阶段轨迹及与baseline差异；identity用于显示重放差异，不以一个条件估计噪声总体或宣称参数改善收益。独立确认结果不反馈给未来Agent。此阶段不会启动PPO，也不把脚本调参称为自主进化。
