# 新十秒参考任务预注册

本协议在首批5秒开发结果之后、任何10秒回合启动之前提交。不是旧W3通过，也不改变5秒原规则。沿用STATE_REFERENCE_PROTOCOL_20261026.md的12回合总开发上限、冻结资格及24回合独立复测规则。

## 修改依据与准入增补

5秒batch1四回合均按几何状态到位后闭合，物体随动确认后才提升。进入descend在第150–154步、close第185–190步、probe第209–214步、lift第225–231步；离5秒结束仅剩0.38–0.50秒，提升目标仍有约0.30m误差，未到达任务目标、持稳0/4。没有>1mm关节越界。控制器已避免旧教师的盲目阶段切换，但没有证明五秒内不可达。

首版开发协议列举的延时准入只涵盖接近/下降/抓取阶段耗尽时限，没有覆盖“已验证抓取，正在正式提升，时限结束”。首批原始报告time_extension_evidence=false和qualified_for_confirmation=false均保留。本补充明确增加后一种准入：原始逐步轨迹存在object_follows_probe_not_contact_alone转换，末态lift且以250步horizon结束、尚未有效持稳。它只授权新的开发任务版本，不改变任何结果门槛。

## 新批次

batch2固定4个新0.1kg条件，状态控制参数与batch1相同，GPU2、同硬件、同执行层、同物理步长和固定目标。唯一任务变化为时限5→10秒，ID为state-reference-h10-v1，最多500控制步。保持0.05m/0.2m/s/0.30秒有效持稳要求、>1mm监测及原严重边界。不能把本版本的通过计为旧五秒任务通过。

如本批达到≥3/4有效持稳且无>1mm关节越界或严重事件，冻结本批实际源码/配置，注册新的0.1/0.4kg各6条件，reference和同源强制张爪各12回合独立复测。否则剩余最多4个开发回合只允许有证据支持的教师参数修正；所有修改仍先提交、再注册。总开发不超过12，复测不重复挑选种子。

## 接触测量范围澄清

安装版本base_contact_sensor_data.py明确实现force_matrix_w→normal_force_matrix_w，net_forces_w→net_normal_forces_w，且提示PhysX没有返回总接触力。因此本批显式读取两种normal字段，数值与旧别名相同；净接触量和cube配对量都只覆盖法向分量，切向接触力未测量。此前“净力/cube-filtered力”现明确限定为这些法向量，不推翻原始数值或作完整接触安全声明，也不能从差值唯一判断桌面、自碰撞或其他来源。
