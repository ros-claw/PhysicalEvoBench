观测：仿真状态位置、物体速度、真实手指开度、指物法向力、公开目标。接触真值不是视觉。支撑接触、切向力、真实 solver 关节力矩没有测量。

新接口提供 frame-relative 目标、公开标量比较、AND/OR、连续 dwell。v2 拒绝旧 place_* 隐藏固定目标别名。phase 名不决定该执行协议的积分启用。最多16节点、2恢复、64转移，全局20s。

评分与旧 T1 相同物理要求：先抬升≥.05m、水平移动≥.08m；目标 XY<.05m/Z<.025m、速度≤.10m/s、双指≥.035m、末端距物体≥.06m，连续稳定≥.50s。不扩大半径或延长时限。
