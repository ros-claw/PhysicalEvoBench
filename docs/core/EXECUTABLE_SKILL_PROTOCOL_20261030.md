# Executable-Skill Learning：首轮适应 pilot

主问题是把正常已有抓取/搬运能力用于释放和落稳，并在新目标位置复用。支持与查询共享对象和夹持/卸载机制，覆盖 0.1/0.4 kg；质量、seed、条件 ID 只在评估器。状态、公开目标与指物法向接触可以被程序读取；不是视觉赛道，桌面支撑接触未测量。

旧 T0 保留为回归；旧 T1 v2-dev 失败与 12 回合停止记录不变。当前候选为 `core-place-public-v3-dev`：公开目标取代解释器里的固定目标；同一受限语言可表达实际开度、速度、目标误差、AND/OR、连续满足。固定执行器使用真实双指接触决定既有有界积分启用，失去接触以 0.2s 常数平滑卸载，不看 phase/node 名。驱动、IK、目标范围/速度包络与旧版一致。不是 Agent 学会控制器补偿。

任务资格先于方法比较。资格条件新 seed，4 个代表条件覆盖正负 Y 目标和两类质量；比较 starter、公开 aperture 修改、冻结强参考、同参考重放，另有四个新查询目标几何的参考开发确认（独立 seed，不是正式查询成绩）和两个 forced-open。要求强参考 4/4、新目标参考 4/4、负参考 0/2、参考与 starter 差异大于强参考 identity 差异、无硬边界事件。这是有限题目资格，不是学习总体统计。失败可回到独立 DEV，但不改写旧结果；不按指定模型输赢选题。

共同起点是正常旧抓取/搬运/定时释放程序，未故意调坏。开发强参考不注入模型上下文。全部方法使用同一公开空间和执行器。全程序作为 JSON 数据，无任意代码、状态写入或评分读取。模型只能读序列化上下文，原始日志不成为参与者文件工具。

首轮设两条独立启动的模型学习实例，各自支持 4 条件、查询 4 条件。支持目标 `(0.62,+0.12)` 与 `(0.60,-0.12)`，查询目标 `(0.58,+0.10)` 与 `(0.64,-0.08)`，中心 Z 为公开场景目标 0.021m。新目标仍需真实查询可达性验证；不得把某个模型失败自动解释为题目不可达。所有实例/方法全部冻结后才开始查询。

方法：

- Frozen：相同 starter，零学习。
- No-Feedback Designer：同一模型、同起始信息与语言，仅自身推理，可 revise/freeze；不给真实物理反馈。
- Feedback Learner：可 run_trial/revise/freeze，最多 8 实践回合，可主动选择句柄，可提前冻结。
- Score-only Search：4 个预先存档候选 × 完全相同的 2 个支持条件（两类质量），共 8 回合。以共同小批成功总数选择，平局保留先出现者。候选包括 starter、随机固定开度阈值、低速门限和 1s 等待，详见 configs/learning/search_candidates.json。它是有限提案族，不能代表整个图空间最强搜索；没有隐藏质量/测试反馈。
- Artifact deletion：新原生实例恢复精确 starter，没有重新学习；是经验依赖对照，不是另一条学习轨迹。

两个模型方法上限一致：10 次调用、300k input /48k output tokens，120s/调用。实际费用分别报告，提前冻结不要求补齐预算。现有 CLI 传输每次临时会话启动；这不是完整原生 Agent harness。程序运行期间测试模型调用为零，文本记忆不参与低层执行。模型实际 provider events/usage 全部留档，模拟进程含冷启动和等待开销。重放不是独立学习样本。

查询每实例 5 arms ×4 =20 回合；学习最多 8+8=16，因此首轮总物理预留上限 72。所有查询任务分母固定；无效提交记参与者失败与零分，仿真基础设施故障单独保留。未知模型 usage 写 unknown，不能填零。

报告每实例初始/最终、反馈相对无反馈、产物相对删除、搜索相对初始，及分子分母、费用、风险和实际动作限幅。配对区间为固定两条学习轨迹内的条件 bootstrap，不能据此宣称跨学习总体稳定。多任务迁移/共享技能保持不在本轮；旧 library 参数复制归属框架，旧程序独立槽位保持不算共享技能抗遗忘。

任务是否合格与模型是否获益分别验收；允许零和负收益。无需强迫模型先失败或必须修改。若候选尚不具可达性或可分辨响应，不扩大模型实验。
