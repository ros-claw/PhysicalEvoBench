# PhysicalEvoBench v0.1.0 — real physical adaptation harness MVP

This release implements an auditable Franka Lift mass-adaptation track on pinned Isaac Lab-Arena.
It freezes the official model, learns a bounded executable skill parameter from train feedback,
validates promotion/rollback, freezes versions and scores matched heldout conditions independently.

Two real 48-episode executions are included, one from a fresh public clone and separate runtime:

| Execution | Gate | Frozen test | Final agent test | Paired difference interval |
| --- | --- | --- | --- | --- |
| Initial | rollback | 3/16 | 4/16, unchanged skill | [0, 18.75] pp |
| Fresh clone | promote | 2/16 | 3/16, gain 1.05 | [-12.5, 25] pp |

Both observed differences were +6.25 pp. The first is replay variability between identical skills;
the second has an interval spanning degradation and higher test joint-limit sample counts.
**This release demonstrates a working evaluation protocol, not stable algorithmic improvement.**
The executions repeat the same protocol seed and 16 conditions, not independent seed studies.

Validation includes 27 CPU tests, GitHub Actions, independent action/score/manifest/budget auditing,
the official pretrained physics rollout, paired mass/inertia pilot checks, and complete fresh-clone
GPU execution. Real wrist-camera video replays are separately budgeted and excluded from scores.

The evidence bundle contains raw episodes, action/state traces, initial conditions, hashed skills,
candidate requests, validation decisions, manifests, metrics, audit reports, HTML and actual video.
Install and reproduction commands are in README.md and docs/reproducibility.md.

Limits: state observations, public heldout manifests, GPU physics variability, limited pilot seeds,
no budget-matched random search, and no collision sensing or complete safety guarantee.
The NVIDIA pretrained weights remain separately licensed for non-commercial use and are not included.
