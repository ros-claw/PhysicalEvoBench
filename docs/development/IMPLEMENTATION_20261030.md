# Executable-Skill Learning 1030 实施计划

本轮依据根目录两份 1030 文档；旧 1027 成绩和停止记录不变。主赛道为固定低层执行、固定基础模型、测试期仅执行冻结技能。

工作分为 DEV、QUALIFICATION、BENCHMARK；任务单独选择。T0 regression 的新目录物理 smoke 不依赖 T1 或旧 B1。新目录共享本机安装的原生运行依赖和外置许可模型，不宣称另一台机器或全新原生安装。

新任务候选是桌面物体的 Lift–Transport–Release：练习与查询共享夹持/卸载机制，查询更换公开目标与重置条件。旧正常抓取能力不削弱；普通放置程序作为 starter，强参考单独开发，不注入学习者。公开状态来自仿真，非纯视觉。

工程范围：新增有界相对目标、可组合公开状态守卫、实际开度/低速/几何误差；缺支撑接触标 not_measured，不用几何估算冒充接触。新控制协议按实测接触启用既有有界积分，脱离时固定平滑卸载，与程序 phase 名无关。旧协议字节语义保留。

工程资源预留最多 48 个 DEV 回合，可重复条件并修代码，每次启动前冻结源码与动作；不是泛化成绩。无需花完预算。任务资格使用冻结接口下未用于调试的条件，对普通起点、强参考、公开修改和同程序重放进行比较；如无可达性与可分辨响应，不扩大模型规模。

首轮比较为 pilot：Frozen、同模型 No-Feedback Designer、Feedback Learner、经验删除。每个模型方法相同模型/空间/调用与 token 上限，No-Feedback 不接触本问题物理反馈。Feedback 可以主动选择公开实践句柄、修改或不修改。候选全部保留；所有测试产物冻结后才测试。Score-only Search 使用共同条件小批比较；若本轮资源不含搜索，不声称优于搜索。目标 2 个独立学习实例，查询每实例 4–6 个配对条件；不宣称跨学习稳定性，样本量不由漂亮曲线决定。

开发失败只影响对应任务；若候选仍不合格，完整交付独立入口与诊断，并明确 Alpha 未完成，不能用 CPU 测试充当学习证据。发布工作采用 feature PR；不自动合并或发布 acceptance release。
